## Теорія

### Як влаштована веб-сторінка — 5 хвилин

Кожна сторінка в інтернеті складається з трьох шарів:

```
┌─────────────────────────────────┐
│           HTML                  │  ← Структура (кістки)
│  Заголовки, тексти, зображення, │    Що є на сторінці
│  кнопки, форми                  │
├─────────────────────────────────┤
│           CSS                   │  ← Стиль (одяг)
│  Кольори, розміри, відступи,    │    Як це виглядає
│  шрифти, анімації               │
├─────────────────────────────────┤
│        JavaScript               │  ← Поведінка (мозок)
│  Що відбувається при натисканні,│    Що це робить
│  валідація, інтерактивність     │
└─────────────────────────────────┘
```

**Тобі НЕ потрібно вчити ці мови.** Потрібно лише розуміти що кожна робить, щоб формулювати промпти:

- "Додай секцію з текстом" → HTML
- "Зроби фон синім" → CSS
- "При натисканні кнопки покажи форму" → JavaScript

### HTML — Мінімум що потрібно знати

HTML використовує теги — це як контейнери для контенту:

```html
<h1>Це заголовок</h1>
<p>Це параграф тексту</p>
<img src="photo.jpg" alt="Опис фото">
<a href="https://google.com">Це посилання</a>
<button>Натисни мене</button>
```

**5 тегів які варто знати:**
![[5 тегів які варто знати.png]]

### CSS — Мінімум що потрібно знати

CSS задає як елементи виглядають:

```css
h1 {
  color: blue;         /* колір тексту */
  font-size: 48px;     /* розмір шрифту */
  text-align: center;  /* вирівнювання по центру */
}
```

**Що варто знати для промптів:**
- **Кольори** — можна назвою (red, blue) або кодом (#FF0000, rgb(255,0,0))
- **Розміри** — пікселі (px), відсотки (%), відносні одиниці (rem)
- **Відступи** — margin (зовнішній) та padding (внутрішній)
- **Flexbox / Grid** — способи розташування елементів (просто знай ці слова)

### Адаптивність (Responsive Design)

Сайт має виглядати добре і на комп'ютері, і на телефоні. У промпті достатньо сказати:
```
Зроби сторінку адаптивною — має добре виглядати на мобільних пристроях.
На десктопі — 2 колонки, на мобільному — 1 колонка.
```

Claude Code знає як це реалізувати технічно. Тобі не потрібно знати медіа-запити — достатньо сказати "щоб на телефоні не виглядало як катастрофа".

### Референси дизайну — головна зброя вайбкодера

Ось секрет, який зекономить тобі години: **не описуй дизайн словами — покажи його.**

AI набагато краще працює коли бачить приклад. Є кілька способів надати референс:

#### Спосіб 1: Скріншот існуючого сайту

Знайшов сайт який подобається? Зроби скріншот і покажи AI:
```
Подивись на цей скріншот [прикріпи файл].
Створи лендінг з такою ж структурою та стилем, 
але для [мій продукт]. Збережи загальний layout, 
кольорову палітру та типографіку.
```

Cursor підтримує зображення в чаті — просто перетягни скріншот у вікно.

#### Спосіб 2: Скачати HTML існуючої сторінки

Побачив лендінг який хочеш як базу? Скачай його HTML:

1. Відкрий сайт у браузері
2. Ctrl+S → "Зберегти як" → "Веб-сторінка, тільки HTML"
3. Поклади файл у проєкт як `reference.html`
4. Скажи Claude Code:
```
Подивись на reference.html — це референс дизайну.
Візьми з нього: загальну структуру, стиль карток, 
кольорову схему. Створи на цій основі лендінг 
для [мій продукт]. Контент та тексти — свої.
```

AI розбере структуру, зрозуміє стилі та створить щось подібне з твоїм контентом.

#### Спосіб 3: Кольори, шрифти та настрій

Якщо повного референсу немає, опиши дизайн-систему:
```
Дизайн:
- Кольори: основний #2563EB (синій), фон #F8FAFC (світло-сірий), 
  акцент #F59E0B (жовтий)
- Шрифт заголовків: Inter Bold, 48px
- Шрифт тексту: Inter Regular, 16px
- Стиль: мінімалістичний, багато повітря, заокруглені кути (12px)
- Настрій: професійний але дружній, як Stripe або Linear
```

#### Спосіб 4: Готовий шаблон дизайн-системи

Ти можеш створити файл `DESIGN.md` і використовувати його як шаблон для всіх проєктів:

```markdown
# Дизайн-система проєкту

## Кольори
- Primary: #2563EB
- Secondary: #64748B  
- Accent: #F59E0B
- Background: #FFFFFF
- Surface: #F8FAFC
- Text: #1E293B
- Text Light: #64748B

## Типографіка
- Заголовки: Inter, Bold
- Текст: Inter, Regular
- Код: JetBrains Mono

## Компоненти
- Кнопки: заокруглені (border-radius: 8px), з тінню при hover
- Картки: білий фон, тінь sm, заокруглення 12px
- Відступи: кратні 4px (4, 8, 12, 16, 24, 32, 48)

## Натхнення
- stripe.com — чистота та простота
- linear.app — сучасний та мінімалістичний
- vercel.com — контрастний та bold
```

Claude Code прочитає цей файл і буде автоматично дотримуватися стилю у всьому проєкті.

### Структура типового лендінгу

```
┌──────────────────────────────┐
│         HEADER               │  Логотип + навігація
├──────────────────────────────┤
│                              │
│          HERO                │  Головний банер з CTA
│                              │
├──────────────────────────────┤
│        FEATURES              │  Переваги / можливості
├──────────────────────────────┤
│       TESTIMONIALS           │  Відгуки клієнтів
├──────────────────────────────┤
│        PRICING               │  Тарифи (опціонально)
├──────────────────────────────┤
│          CTA                 │  Заклик до дії
├──────────────────────────────┤
│         FOOTER               │  Контакти, соцмережі
└──────────────────────────────┘
```

## Практика

### Проєкт: Лендінг

**Наскрізний приклад (Amazon Competitor Tracker):**
Ми зробимо лендінг для нашого інструменту моніторингу конкурентів. Це та ж сторінка яку потім покажемо колегам: "ось що робить наш інструмент, ось чому він корисний".

**Або обери свій варіант:**
- **А)** Інструмент аналітики для своєї ніші
- **Б)** Внутрішній дешборд для команди
- **В)** Калькулятор/порівняльник для клієнтів
- **Г)** Свій варіант

### Крок 1: Підготовка та референси (10 хв)

1. Створи папку проєкту:
   ```bash
   mkdir landing-project
   cd landing-project
   git init
   ```

2. **Знайди 1-2 референси дизайну:**
   - Зайди на [Land-book.com](https://land-book.com/) або [One Page Love](https://onepagelove.com/)
   - Знайди лендінг який подобається за стилем
   - Зроби скріншот або скачай HTML (Ctrl+S)
   - Поклади в папку `references/`

3. **Створи CLAUDE.md** з описом продукту та стилю

4. **Створи DESIGN.md** — опиши кольори, шрифти, стиль

5. Запусти Claude Code:
   ```bash
   claude
   ```

### Крок 2: Hero-секція (10 хв)

```
Створи файл index.html з hero-секцією для лендінгу.
Дотримуйся стилю з DESIGN.md.

Включи:
- Навігацію зверху (логотип ліворуч, 3 пункти меню праворуч)
- Великий заголовок з описом продукту
- Підзаголовок в 1-2 речення
- Кнопку CTA "Спробувати безкоштовно"
- Фонове зображення або градієнт

Сторінка має бути адаптивною.
```

**Перевір результат:** відкрий в браузері через Live Server. Не подобається? Скажи що саме змінити — AI виправить за секунди.

### Крок 3: Секція переваг (10 хв)

```
Додай секцію "Переваги" після hero. 
3 картки в ряд (на мобільному — вертикально):
- Іконка (використай emoji)
- Заголовок переваги
- Короткий опис (2-3 речення)

Дотримуйся стилю з DESIGN.md для карток.
```

### Крок 4: Відгуки (10 хв)

```
Додай секцію "Відгуки клієнтів" після переваг.
3 відгуки з:
- Фото (використай placeholder від ui-avatars.com)
- Ім'я та посада
- Текст відгуку (2-3 речення)
- Рейтинг зірочками

Стиль: світло-сірий фон секції, білі картки відгуків.
```

### Крок 5: CTA та Footer (10 хв)

```
Додай:
1. Секцію CTA перед футером — заклик до дії з кнопкою та коротким текстом.
   Фон — основний колір бренду.

2. Footer з:
   - Логотип та короткий опис компанії
   - Колонка "Продукт" з 4 посиланнями
   - Колонка "Компанія" з 4 посиланнями  
   - Соцмережі (іконки)
   - Копірайт 2026
```

### Крок 6: Фінальні штрихи (10 хв)

```
Переглянь весь лендінг та:
1. Додай плавну прокрутку до секцій
2. Зроби навігацію фіксованою при прокрутці
3. Додай hover-ефекти на кнопки та посилання
4. Перевір адаптивність — все має добре виглядати 
   на екрані шириною 375px (iPhone)
5. Додай favicon
```

### Крок 7: Збережи в Git (5 хв)

```bash
git add .
git commit -m "Лендінг для [назва продукту] — повна версія"
```

## Питання для самоперевірки


1. Ти написав "зроби гарний лендінг" і отримав щось генеричне. Як покращити промпт використовуючи референси?

2. DESIGN.md описує кольори `Primary: #2563EB`, шрифт `Inter`, стиль `мінімалістичний`. Якщо тепер попросити AI "створи нову секцію" — чи потрібно знову описувати стиль?

3. Ти попросив AI "зроби весь лендінг з 6 секціями". Результат: щось зроблено, але hero без кнопки, відгуки без фото, footer кривий. Де помилка в підході?
