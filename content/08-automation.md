## Теорія

### Що можна автоматизувати

Автоматизація — це коли комп'ютер робить повторювані задачі замість тебе. Якщо ти робиш щось більше 3 разів — це кандидат на автоматизацію.

| Задача | Ручна робота | Автоматизація |
|--------|-------------|---------------|
| Моніторинг конкурентів | Заходиш на 50 сторінок, записуєш ціни | Скрипт збирає все за 30 секунд |
| Пошук аномалій в даних | Переглядаєш таблицю очима | Алгоритм знаходить відхилення миттєво |
| Порівняння показників | Excel, зведені таблиці, ручні формули | Дешборд з автоматичним оновленням |
| Відповіді на типові питання | Пишеш одне й те саме щодня | Бот відповідає автоматично |
| Генерація звітів | Збираєш дані, форматуєш | Скрипт генерує звіт щовечора |

### Чому Python, а не JavaScript?

До цього ми працювали з JavaScript (Next.js, React). А тут раптом Python. Чому?

Мов програмування багато, кожна сильна у своєму. Перед розробкою будь-якого модуля варто підібрати найкращий інструмент під задачу — а не використовувати один для всього.

| Задача | Краща мова | Чому |
|--------|-----------|------|
| Веб-інтерфейс (фронтенд) | JavaScript (React, Next.js) | Працює в браузері, інтерактивність |
| Автоматизація, скрипти, аналітика | Python | Найбільша бібліотека інструментів (pandas, requests) |
| Бекенд API | JavaScript або Python | Обидва підходять, залежить від команди |
| Мобільні додатки | Swift, Kotlin, React Native | Спеціалізовані під платформу |

**Реальний приклад — з чого побудована LMS на якій ти зараз навчаєшся:**
- **Фронтенд** (те що бачиш в браузері) — JavaScript + React
- **Бекенд** (логіка, API, авторизація) — Python + Django
- **База даних** — PostgreSQL
- **Автоматизація** (розсилки, нагадування) — Python-скрипти

Чому такий набір? Фронтенд на JS бо це стандарт для браузера. Бекенд на Python бо Django дає готову систему: адмін-панель, авторизацію, безпеку — швидко і надійно. Автоматизація на Python бо pandas обробляє дані в рази простіше ніж аналоги.

**Для вайбкодера головне:** ти не вчиш мову — ти кажеш Claude що хочеш автоматизувати, а він обирає правильний інструмент. Але розуміти ЧОМУ Python для скриптів — корисно.

**Що потрібно знати:**
- Python-скрипт запускається через `python script.py`
- Бібліотеки встановлюються через `pip install назва`
- Синтаксис знати не потрібно — Claude напише за тебе

### Типи автоматизацій

#### 1. Скрипти збору та аналізу даних

Скрипт — це файл з інструкціями який виконується від початку до кінця. Найпотужніший кейс — **аналітика конкурентів та ринку**.

**Реальний приклад — моніторинг Amazon лістингів:**

```
Що робить скрипт:
1. Щовечора о 21:00 витягує дані 50 конкурентних лістингів через API
2. Зберігає в базу даних
3. Порівнює з вчорашніми значеннями — знаходить зміни
4. Рахує прибуток за поточний тиждень vs минулий тиждень
5. Рахує прибуток за поточний місяць vs минулий місяць
6. Знаходить аномалії — різке зростання або падіння
7. Сортує за приростом заробітків
8. Генерує звіт та відправляє в Telegram
```

**Що отримуєш:**
```
📊 Вечірній звіт конкурентів — 05.05.2026

🔥 Топ-3 за зростанням сьогодні:
1. [Конкурент X] — Revenue +34%
2. [Конкурент Y] — Revenue +22%
3. [Конкурент Z] — Revenue +18%

📉 Падіння:
1. [Конкурент W] — Revenue -15%

📅 Тиждень (28.04 - 04.05) vs минулий:
Загальний ринок: +8.3% ($450K → $487K)

📅 Місяць (квітень) vs березень:
Загальний ринок: +12.1% ($1.8M → $2.02M)

⚠️ Аномалії:
- [Конкурент X]: різке зростання 3 дні поспіль (+34%, +28%, +41%)
  Можлива причина: новий лістинг або PPC-кампанія
```

Це не фантастика — це реальний скрипт на ~200 рядків Python, який Claude Code напише за 20 хвилин.

#### 2. Telegram/Discord боти

Бот — це програма яка відповідає на повідомлення в месенджері.

**Що може бот:**
- Відповідати на FAQ
- Сповіщувати про аномалії ("Конкурент X змінив ціну на 30%!")
- Збирати дані від користувачів (опитування, форми)
- Давати швидкий доступ до аналітики ("/report today", "/compare week")

**Промпт для Telegram-бота:**
```
Створи Telegram-бота на Python який:
1. /start — привітання та опис можливостей
2. /report — показує сьогоднішній звіт конкурентів
3. /compare week — порівняння поточного та минулого тижня
4. /compare month — порівняння місяців
5. /anomalies — показує аномалії за останні 7 днів
6. /top — топ-10 за зростанням за обраний період

Використай python-telegram-bot бібліотеку.
Токен бота я отримаю через @BotFather.
```

#### 3. No-code автоматизації (n8n, Make)

**n8n** та **Make (Zapier)** — це візуальні інструменти де ти з'єднуєш блоки як конструктор:

```
[Тригер: Щодня 21:00]
    ↓
[API: Отримати дані конкурентів]
    ↓
[Обробка: Порівняти з вчорашніми]
    ↓
[Фільтр: Зміна > 10%]
    ↓
[Дія: Відправити в Telegram]
```

**Коли використовувати no-code:**
- Інтеграція між сервісами (Google Sheets → Telegram → Email)
- Прості автоматизації де не потрібна складна логіка
- Потрібно швидко і без жодного рядка коду
- Нетехнічна людина має підтримувати workflow

**Коли писати скрипт:**
- Складна обробка та аналіз даних (порівняння по періодах, аномалії)
- Нестандартна логіка з умовами
- Потрібна швидкість або великий масштаб (1000+ записів)
- Потрібна гнучкість у форматуванні звітів

#### 4. Cron-задачі (виконання за розкладом)

Cron — це планувальник який запускає задачі за розкладом:

```
Щодня о 21:00    → Збери дані конкурентів та згенеруй звіт
Кожну годину     → Перевір ціни на аномалії
Щопонеділка 9:00 → Тижневий звіт з порівнянням
1-го числа 10:00 → Місячний звіт з трендами
```


#### Крок 2: Структура даних (10 хв)

```
Створи структуру проєкту для аналітики конкурентів:

1. Файл models.py — опис даних:
   - Listing: asin, title, brand, price, rating, reviews_count, 
     bsr_rank, estimated_revenue, date
   
2. Файл config.py — конфігурація:
   - Список 50 ASIN конкурентів (тестові дані)
   - API ключі з .env
   - Параметри порівняння

3. Створи seed_data.py — генерація тестових даних:
   - 50 лістингів x 90 днів (3 місяці)
   - Реалістичні зміни цін (±5-15%)
   - Декілька аномалій (різкий зріст 30-50%)
   - Зберегти в CSV для початку (потім перенесемо в Supabase)
```

#### Крок 3: Аналітичний движок (15 хв)

```
Створи analyzer.py з класом CompetitorAnalyzer:

1. daily_changes() — порівняння сьогодні vs вчора:
   - Зміна ціни (абсолютна та %)
   - Зміна BSR
   - Зміна estimated revenue
   - Сортування за найбільшою зміною revenue

2. weekly_comparison(week1, week2) — два довільних тижні:
   - Сума revenue за кожний тиждень
   - Зміна %
   - Топ зростання та падіння

3. monthly_comparison(month1, month2) — два довільних місяці:
   - Аналогічно weekly але за місяць

4. detect_anomalies(days=7, threshold=20) — аномалії:
   - Лістинги де зміна > threshold% за один день
   - Послідовне зростання 3+ днів поспіль
   - Різке падіння BSR (= зростання продажів)

5. flexible_comparison(period_type, period1, period2):
   - period_type: "day", "week", "month"
   - Вибір конкретних дат/тижнів/місяців для порівняння
   - Групування та сортування результатів

Використовуй pandas. Дані з CSV (потім замінимо на Supabase).
```

#### Крок 4: Генерація звітів (10 хв)

```
Створи reporter.py:

1. Функція generate_text_report(analysis_result) → str
   - Форматований текстовий звіт (для Telegram)
   - Emoji для візуалізації (📈📉⚠️🔥)
   - Таблиці з даними

2. Функція generate_html_report(analysis_result) → str
   - HTML-звіт з таблицями та графіками
   - Кольорове кодування (зелений = ріст, червоний = падіння)
   - Можна відкрити в браузері

3. Функція export_csv(analysis_result, filepath)
   - Експорт для подальшої обробки в Excel

Виклик: python reporter.py --period today
         python reporter.py --compare-weeks 2026-W18 2026-W17
         python reporter.py --compare-months 2026-04 2026-03
```

## Питання для самоперевірки

1. Аналітик щодня вручну перевіряє 50 сторінок Amazon і записує ціни в Excel. Це підходить для автоматизації тому що...

2. Скрипт запускається один раз і завершується. Бот працює постійно і чекає команд. Для щовечірнього збору даних краще підходить...

3. Ти хочеш підключити Google Sheets → фільтр → Telegram. Код чи no-code (n8n/Make)?

4. Конкурент X мав revenue $10K вчора, а сьогодні $14K. Зміна = +40%. Якщо threshold аномалій = 20%, це буде позначено як аномалія тому що...

5. Токен Telegram-бота `6123456:AAF...` зберігається в .env файлі, а не в коді тому що...
