# Модуль 1A: MCP та Skills — Суперсили для Claude

> **Тривалість:** 15 хв теорія + 10 хв практика
> **Результат:** Розуміння як розширити можливості Claude через MCP та Skills

---

## Теорія

### Чому Claude "сліпий" без MCP

Уяви: ти найняв крутого senior-розробника. Посадив за стіл. І не дав комп'ютер. Не дав інтернет. Не дав доступу до Google Drive команди. Не дав можливості відкрити браузер.

Він геній — але без інструментів зробить нуль.

**Це і є Claude "з коробки":**
- ❌ Не бачить інтернет — його знання обмежені датою навчання. Він не знає що було минулого тижня
- ❌ Не може зайти на твій сайт і подивитись як він виглядає в реальності
- ❌ Не бачить твої Google Drive, Notion, Figma, Slack
- ❌ Не може погуглити "як правильно зробити X в 2026 році"

**MCP (Model Context Protocol)** — це стандарт від Anthropic, який дає Claude доступ до зовнішнього світу. Це як підключити йому очі, руки та інтернет.

```
Без MCP:  "Я думаю що в Tailwind v4 синтаксис ось такий..."
          (а він вже застарів — Claude вчився півроку тому)

З MCP:    [Claude гуглить через Perplexity → читає актуальні docs]
          "Перевірив документацію Tailwind v4.2 — 
           правильний синтаксис ось такий..."
```

### Топ 5 MCP які треба підключити одразу

| MCP                        | Що дає Claude                                                  | Чому критично                              |
| -------------------------- | -------------------------------------------------------------- | ------------------------------------------ |
| **Perplexity**             | Реальний інтернет — актуальна інфа, документація, новини       | №1 — без нього Claude живе в минулому      |
| **Playwright (Microsoft)** | Справжній браузер — відкриває твій сайт, клікає, тестує        | Працює БЕЗ API-ключів, просто запустив     |
| **Google Drive**           | Доступ до Docs, Sheets, PDF в Google                           | Брифи, ТЗ, спецификації лежать там         |
| **Figma**                  | Читає макети прямо з Figma                                     | Реалізація точно по дизайну, не "схоже на" |
| **Glif**                   | Бібліотека AI-міні-інструментів (картинки, обробка, агенти)    | Готові генеративні workflow з коробки      |

**Perplexity — must have №1.**
Без нього Claude радить застарілі бібліотеки і код. З ним — він гуглить, читає поточні docs, перевіряє чи бібліотека ще жива. Це різниця між phantom imports і робочим кодом.

**Playwright від Microsoft — без головного болю.**
На відміну від багатьох MCP, не потребує API-ключів. Запустив — Claude відкриває реальний браузер і взаємодіє з твоїм сайтом як людина.

```
Ти: "Перевір що форма реєстрації працює. Заповни тестовими даними і подивись чи приходить підтвердження"
Claude: [відкриває браузер] → [заповнює форму] → [клікає Submit]
        → "Працює, але валідація email не спрацьовує — введи 'abc' і
           воно приймає. Виправити?"
```

**Google Drive — для роботи з командою.**
Бриф у Google Docs? Дані в Sheets? Claude читає напряму, без копіпасту і експорту.

**Figma — точно по дизайну.**
Замість скріншотів і "зроби схоже" — Claude відкриває макет і відтворює його 1:1: кольори, відступи, шрифти, компоненти.

**Glif — конструктор AI-інструментів.**
Тисячі готових AI-workflows (генерація OG-картинок, обробка фото, мікро-агенти). Підключив — Claude вміє цим всім користуватись.

### Skills — упакована експертиза

Якщо MCP — це **руки та очі** Claude, то Skills — це **спеціалізовані мізки**.

**Skill** — це пакет інструкцій який робить Claude експертом у конкретній області. Підключив — і він поводиться як senior-спеціаліст у цій ніші, а не як універсал.

```
Без skill:    Claude дає універсальні поради по дизайну
З UX/UI skill: Claude думає як senior-дизайнер — застосовує методології,
               радить по типографіці, grid system, accessibility,
               візуальній ієрархії
```

**Корисні skills для вайбкодера:**

| Skill                  | Що змінюється                                              |
| ---------------------- | ---------------------------------------------------------- |
| **UX/UI Pro Max**      | Поради рівня senior-дизайнера: типографіка, grid, hierarchy |
| **SEO Expert**         | Оптимізація під сучасні правила Google і AI-пошук          |
| **Copywriter**         | Сильні заголовки, CTA, тексти що конвертують               |
| **Code Reviewer**      | Перевірка коду на безпеку, performance, best practices     |
| **Database Designer**  | Правильна структура таблиць, індекси, відносини            |

**Де шукати skills:**
- **claude.ai/skills** — офіційний каталог Anthropic
- **GitHub** — пошук `claude skill [тема]` або `awesome-claude-skills`
- **Створи свій** — Skill це просто markdown з інструкціями. Описав експертизу — отримав skill, який можна перевикористовувати

### Як підключити

**MCP:**
1. Знайшов потрібний — на [mcp.so](https://mcp.so) або в [офіційних docs](https://docs.anthropic.com/en/docs/claude-code/mcp)
2. `claude mcp add [назва]` — або через Cursor Settings → MCP
3. Перезапустив Claude Code → готово

**Skill:**
1. Скопіюй файл skill (markdown)
2. Поклади в `~/.claude/skills/` або в папку проєкту
3. Claude автоматично побачить при наступному запуску

**Підказка для новачка:** Попроси Claude Code — *"Допоможи мені підключити Perplexity MCP, проведи покроково"* — він знайде актуальну інструкцію і пройде з тобою кожен крок.

### Що це все дає разом

```
Звичайний Claude:
"Зроби лендінг" → пише код по своїх знаннях (можливо застарілих)

Claude з MCP + Skills:
"Зроби лендінг для нашого SaaS" →
  1. [Perplexity]      гуглить best practices лендінгів 2026
  2. [Google Drive]    підтягує бриф з Docs команди
  3. [Figma MCP]       читає макет дизайнера
  4. [UX/UI Skill]     застосовує дизайн-методології
  5. [Copywriter Skill] пише сильні заголовки та CTA
  6. [SEO Skill]       додає правильні мета-теги і структуру
  7. [Playwright]      відкриває браузер, тестує що працює
  
Результат: робота рівня агентства, а не "AI накидав щось"
```

### Коли що використовувати

| Ситуація | Інструмент | Чому |
|----------|-----------|------|
| Потрібна нова сторінка/компонент | Claude Code | Бачить весь проєкт, створить файл в правильному місці |
| Швидка правка в одному файлі | Cursor Ctrl+K | Швидше, не потрібно описувати контекст |
| Обговорити підхід, спланувати | Cursor Chat (Ctrl+L) | Діалоговий формат, зручно ітерувати |
| Запустити команду | Claude Code | Може сам запустити npm install, git push |
| Не розумію що робить код | Cursor Chat | Виділив → "поясни" |
| Потрібна актуальна інфа з інтернету | Claude Code + Perplexity MCP | Без нього Claude радить застаріле |
| Перевірити чи сайт реально працює | Claude Code + Playwright MCP | Відкриває справжній браузер, не симулює |
| Реалізувати точно по дизайну | Claude Code + Figma MCP | Читає макет напряму, без скріншотів |
| Дизайн "не дуже" і не знаю чому | Claude Code + UX/UI Skill | Поради рівня senior-дизайнера |

## Практика

### Завдання 1: Підключи Perplexity MCP (5 хв)

1. Запусти Claude Code
2. Напиши: *"Допоможи підключити Perplexity MCP покроково"*
3. Слідуй інструкціям
4. Перевір: *"Загугли яка остання версія Next.js і що нового"*
5. Якщо Claude відповів з посиланнями на актуальні джерела — MCP працює

### Завдання 2: Спробуй Playwright (5 хв)

1. Якщо є запущений сайт (з [[01-claude-interface|модуля 1]]) — попроси Claude:
   *"Відкрий мій сайт на localhost:3000, зроби скріншот, і скажи що можна покращити"*
2. Подивись як Claude сам відкриває браузер і аналізує

## Питання для самоперевірки

1. Claude порадив використати бібліотеку яка вже 2 роки не оновлюється. Який MCP допоміг би уникнути цієї проблеми?

2. Ти маєш макет в Figma і хочеш щоб Claude реалізував його точно. Без MCP ти б робив скріншот і описував словами. З Figma MCP — що зміниться?

3. Claude дає загальні поради по дизайну типу "зробіть красиво". Який тип розширення зробить його порадником рівня senior-дизайнера — MCP чи Skill?
