# Vibe Coding з Claude — Курс для команди

## Про курс

Практичний курс з вайбкодингу для співробітників без досвіду програмування.
Від нуля до робочого MVP — крок за кроком, з практикою після кожного модуля.

Не хвилюйся, ніхто не буде змушувати тебе писати `for (int i = 0; i < n; i++)` — для цього є AI.

## Для кого

- Маркетологи, менеджери, аналітики — будь-хто без досвіду в коді
- Не потрібно знати програмування, HTML, або як працює сервер
- Потрібно: ноутбук, браузер, бажання створювати

## Що ми надаємо

- **Підписка на Claude Pro** — для роботи з AI
- **Cursor Pro** — AI-редактор коду
- **Хостинг та сервер** — для публікації проєктів
- Від тебе — тільки ноутбук і бажання

## Формат

- 11 основних модулів + 2 додаткових (бекапи, дебагінг)
- Теорія (15-25 хв) → Практика (30-60 хв)
- Кожен модуль завершується робочим результатом
- До кінця курсу — повноцінний MVP проєкт

## Ключова ідея

Ти будуєш MVP ітеративно — версія за версією, компонент за компонентом. Не "все і одразу", а "зробив → перевірив → покращив → закомітив". Зламав? Відкотився. Не подобається? Переробив за 2 хвилини.

```
(Модулі 0-5)      (Модулі 6-9)    (після курсу)   (після)      (після)           (після)
```

## Як проходити

1. Модулі йдуть послідовно — кожен будує на попередньому
2. Не пропускай практику — це найважливіша частина
3. **Комітити після кожного кроку** — це страховка
4. Якщо застряг — прочитай модуль 3A (дебагінг)
5. Працюй по одному компоненту за раз — так ефективніше
