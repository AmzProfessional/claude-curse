## Теорія

### Що нам потрібно і навіщо

Перед тим як починати — розберемось, що ми будемо встановлювати і чому саме це:

| Інструмент      | Навіщо                                                  | Аналогія                         |
| --------------- | ------------------------------------------------------- | -------------------------------- |
| **Cursor**      | Редактор з AI — тут бачиш файли та працюєш з кодом     | Як Word, але з AI-помічником     |
| **Terminal**     | Командний рядок — тут говориш з Claude Code             | Як месенджер з Claude            |
| **Node.js**     | Середовище виконання — дозволяє запускати сучасні сайти | Як двигун в авто                 |
| **Git**         | Контроль версій — зберігає історію змін                 | Як Google Docs з історією версій |
| **GitHub**      | Хмарне сховище — зберігає проєкт в інтернеті            | Як Google Drive для коду         |
| **Claude Code** | AI-напарник в терміналі — пише код за тебе              | Як senior-розробник поруч        |

### Cursor

**Cursor** — AI-native редактор коду, побудований на основі VS Code.

Чому Cursor, а не звичайний VS Code:
- AI вбудований прямо в редактор (Ctrl+K, Ctrl+L)
- Глибока інтеграція з Claude (основна модель курсу)
- Автодоповнення коду (Tab) — AI підказує що написати далі
- Всі розширення VS Code працюють

**Розширення які встановимо:**
- **Prettier** — автоформатування коду
- **Live Server** — миттєвий перегляд HTML в браузері
- **Tailwind CSS IntelliSense** — підказки для стилів

### Terminal (Термінал)

Термінал — це текстовий інтерфейс для взаємодії з комп'ютером. Замість натискання кнопок, ти пишеш команди.

**Не лякайся!** Тобі потрібно знати лише 5 команд:

```bash
cd назва-папки     # перейти в папку
ls                 # показати файли в папці
mkdir назва        # створити нову папку
code .             # відкрити поточну папку в Cursor
claude             # запустити Claude Code
```

Все інше — Claude Code зробить за тебе. Серйозно, він сам запускає потрібні команди.

### Node.js

Node.js — це середовище, яке дозволяє запускати JavaScript (мову програмування для вебу) на твоєму комп'ютері.

**Навіщо нам:**
- Сучасні веб-фреймворки (React, Next.js) потребують Node.js
- Менеджер пакетів npm — встановлює бібліотеки одною командою
- Claude Code працює на Node.js

**Яку версію:** LTS (Long Term Support) — стабільна версія.

### Git та GitHub

**Git** — система контролю версій. Відстежує кожну зміну в проєкті.

Уяви Google Docs де ти можеш:
- Повернутись до будь-якої попередньої версії документа
- Зробити "відгалуження" — спробувати щось нове, не зламавши оригінал
- Об'єднати зміни від різних людей

Зламав проєкт о 3 ночі? `git checkout` — і все як було. Це як Ctrl+Z, тільки для всього проєкту і на будь-яку глибину.

**GitHub** — це хмарний сервіс де зберігаються Git-проєкти. Як Google Drive, але для коду.

**Команди Git які потрібно знати:**

```bash
git init                    # ініціалізувати репозиторій
git add .                   # додати всі зміни
git commit -m "опис змін"   # зберегти зміни з описом
git push                    # відправити на GitHub
git status                  # подивитись що змінилось
```

### Claude Code

Claude Code — CLI від Anthropic для роботи з кодом через AI.

**Встановлення:**
```bash
npm install -g @anthropic-ai/claude-code
```

**Запуск:**
```bash
claude
```

Після запуску ти просто пишеш що хочеш зробити — а Claude Code виконує. Він сам створює файли, запускає команди, виправляє помилки.

## Практика

### Крок 1: Встанови Cursor

1. Відкрий https://cursor.com
2. Натисни "Download"
3. Встанови
4. Відкрий Cursor
5. Якщо пропонує імпортувати налаштування VS Code — погоджуйся
6. Встанови розширення: Prettier, Live Server

### Крок 2: Встанови Node.js

1. Відкрий https://nodejs.org
2. Завантаж LTS версію
3. Встанови
4. Перевір в терміналі Cursor (Ctrl+`):
   ```bash
   node --version
   npm --version
   ```
   Повинні показати номери версій. Якщо показали — вітаю, перший крок до вайбкодингу зроблено.

### Крок 3: Встанови Git

1. Відкрий https://git-scm.com
2. Завантаж для своєї ОС
3. Встанови
4. Налаштуй ім'я та email:
   ```bash
   git config --global user.name "Твоє Ім'я"
   git config --global user.email "твій@email.com"
   ```

### Крок 4: Створи акаунт на GitHub

1. Відкрий https://github.com
2. Натисни "Sign Up"
3. Заповни форму
4. Підтверди email

### Крок 5: Встанови Claude Code

1. В терміналі Cursor виконай:
   ```bash
   npm install -g @anthropic-ai/claude-code
   ```
2. Запусти:
   ```bash
   claude
   ```
3. Авторизуйся

### Крок 6: Створи перший репозиторій

1. Створи папку для проєкту:
   ```bash
   mkdir my-first-project
   cd my-first-project
   ```
2. Ініціалізуй Git:
   ```bash
   git init
   ```
3. Запусти Claude Code:
   ```bash
   claude
   ```
4. Напиши Claude:
   ```
   Створи файл index.html з простою сторінкою-привітанням. 
   Додай заголовок "Мій перший проєкт" та параграф 
   "Я щойно налаштував робоче середовище для вайбкодингу!"
   ```
5. Відкрий файл у браузері
6. Збережи в Git:
   ```bash
   git add .
   git commit -m "Мій перший коміт"
   ```

Якщо ти бачиш свою сторінку в браузері — все працює. Можеш зробити скріншот та відправити в чат курсу.

## Типові проблеми

| Проблема | Рішення |
|----------|---------|
| `node: command not found` | Перезапусти термінал після встановлення Node.js |
| `git: command not found` | Перезапусти термінал після встановлення Git |
| Claude Code не запускається | Перевір авторизацію — можливо потрібно заново логін |
| Не можу створити репозиторій | Перевір чи ти всередині правильної папки (`pwd`) |
| Cursor не бачить розширення | Перезапусти Cursor після встановлення |

## Питання для самоперевірки

1. Ти встановив Node.js, але команда `node --version` в терміналі каже "command not found". Найімовірніша причина і що робити?

2. Ти набрав `claude` в терміналі і він запустився. Тепер ти пишеш: "Створи файл index.html з привітанням". Де саме з'явиться цей файл?

3. `git init` створює репозиторій, а `git commit -m "опис"` зберігає версію. Що буде якщо ти зробив 10 змін і жодного коміту, а потім все зламалось?

4. Cursor побудований на основі VS Code. Навіщо тоді окремий Cursor, якщо VS Code безкоштовний?

5. Колега каже "навіщо мені GitHub, якщо проєкт і так на моєму ноутбуці". Що він ризикує?
